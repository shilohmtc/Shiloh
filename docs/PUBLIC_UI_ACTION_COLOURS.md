# Action button colours

Owner-confirmed presentation standard, 24 October 2026:

- Use existing Shiloh green `button--primary` for primary and commit actions.
- Use outlined `button--soft` for secondary actions and Cancel.
- Use the existing red `button--danger` for destructive actions such as Remove.
- Keep clear text labels so colour is never the only distinction.
- Check readable contrast, visible focus and touch targets on phone and desktop.

For saved passkeys: Save name is primary, Rename and Cancel are secondary,
and Remove is destructive. These styles do not change any action's behaviour.
